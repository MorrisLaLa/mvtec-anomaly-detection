# 工作時段規則

時區：台北時間（UTC+8）。

| 時段 | 誰啟動 | 規則 |
|---|---|---|
| 22:00–05:00 | 排程自動啟動（每小時一次，最後一次 04:xx） | 見 `NIGHTLY.md` |
| 05:00–22:00（白天） | 只有使用者叫我才動，不設任何自動排程 | **每次最多工作 20 分鐘** |

## 白天 20 分鐘規則
1. 一開始就用 `date` 記下開始時間（台北時間）。
2. 每完成一個小單元就再用 `date` 檢查已經過多久。
3. 接近 20 分鐘時不再開始新的單元：把進行中的收尾、測試、提交、推送，更新 `PROGRESS.md`，然後停下來回報目前進度與下一步。
4. 不在 20 分鐘內做不完的事就拆小；寧可先交一個可運作的小單元，不要留下半成品。
5. 使用者明確說「這次不限時」才可以超過。

限制（誠實說明）：這是我自行遵守的規則，無法由系統強制中斷；單一長時間的指令（如整套測試約 1 分鐘）可能讓時間略微超出。
